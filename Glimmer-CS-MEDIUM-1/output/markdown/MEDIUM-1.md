(3) t可取0或1

- 若t为1,先将1左移(n - 1),再与x做按位或.

```c
unsigned char res = x | (1 << (n - 1));
```

- 若t为0,先将1左移后的数取反,再与x做按位与.

```c
unsigned char res = x & ~(1 << (n - 1));
```

- 可以通过t的值把两式结合:

```c
unsigned char res = (x & ~(1 << (n - 1))) | (t << (n - 1));
```

(4) 题目要求输出的数是最低位的1,十进制即为2^(n - 1).x取反后,该位置的1变0,右边的0都变为1,再+1产生进位,最终该位置仍然是1.这个过程是补码.如果将x & (~x + 1),只有该位置的1相同,其余位全部为0,输出的正好为2^(n - 1).

并且~x + 1 = -x.

(5) int 和 unsigned int都无法承载100位,所以输入时必须靠字符串或数组.

一开始猜测要分组进行&,结果都为每组第一个数,但大小增加之后发现无法总结分组规律.但能确定的是,由于进位时最低位会归零,每一组若干个数&的结果,相同的最高位1右边全为0.只要找到那一段最长的公共前缀即可.

```c
#include <stdio.h>
#include <string.h>
#define MAX 200

int main(){
    char a[MAX], b[MAX], ans[MAX];
    char A[MAX], B[MAX];
    scanf("%s %s",a,b);

    int la = strlen(a);int lb = strlen(b);
    int n = (la > lb) ? la : lb;

    for(int i = 0; i < n; i++){
           A[i] = '0';
    }strcpy(A + (n - la), a);
    for(int i = 0; i < n; i++){
           B[i] = '0';
    }strcpy(B + (n - lb), b);

    for(int i = 0; i < n; i++){
        if(A[i] == B[i]){
            ans[i] = A[i];
        }
        else{
            for(int j = i; j < n; j++){
                ans[j] = '0';
            }
            break;
        }
    }
    ans[n] = '\0';
    printf("%s\n", ans);
}
```

(6) 思考题

- ***逻辑运算与位运算:*** 逻辑运算工作在"真值层面",一位一句话,带短路求值,是控制流的工具;位运算工作在"比特层面",保留全部位宽,是数据加工的工具.可以说,逻辑运算丢失了数值信息.相同点是,二者有相同的真值表.
- ***位运算的性质:*** 位运算的性质可以分成四层:代数律(交换/结合/分配/德摩根/自逆),位级恒等式(x&(-x),x&(x-1),~(x)),与算术的桥(移位 = 乘除 2 的幂,a+b = (a^b) + 2(a&b),-x = ~x+1),以及工程用途(掩码、位图、状态压缩、popcount).可以做到判奇偶,读/写某一位,数的个数,取低n位掩码等
- ***右移区别的原因:*** 整数用补码存储,因为只有一个0,还能统一减法为加法,溢出判断简单.补码最高位权重为-2^(n - 1).算术右移必须为负数补1才符合数学规律,逻辑右移无符号位,补0即可.两种右移语义不同.
