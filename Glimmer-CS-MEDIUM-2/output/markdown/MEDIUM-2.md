## 任务3.1

(1) 符号位都是1位,其他两位:

- ***float:*** 阶码8位,尾数23位;
- ***double:*** 阶码11位,位数52位.

(2) ***Bias的计算公式:*** Bias = 2^(阶码位数) - 1.

- 因为阶码有2^(解码位数)个编码,但是0和255位需要表示特殊值,去掉之后正中间的位数是一个小数,向下取整,达到正负基本对称.
- ***意义是什么:*** 首先能让有正有负的指数能被无符号字段存储,并且大小顺序与原数一致;其次,能用比较整数的电路直接比较浮点数的大小.

(3) ***非规格化数的特点:*** 阶码全为0,此时尾数前方的不是1而是0,实际阶码固定都为1 - Bias.

(4) ***特殊阶码模式:***

- 阶码全1尾数全0时,指±∞;
- 阶码全1尾数非0时,指NaN.

## 任务4.1

- 一些思考:

  - 对阶的目的,是和科学计数法一样,让尾数能进行加减运算.
  - 不用大阶向小阶看齐,是由于大阶尾数左移后,左边没有空位,最高位的1会被挤出寄存器,让数值崩溃.降阶时要减少E
  - 为了输出0和1,用数组代替浮点数进行模拟,需要在开始和结束时将数组的几个部分用位运算写成整数.
  - siga和sigb需要提前把规格化数自带的1补上,就是将第三位变成1.
  - 将sig规格化右移时,既将sig转化成四位,由达成了向零舍入.之后将自带的1去掉即可.

```c
#include<stdio.h>

void sum(const char* a,const char* b, char out[9]){
    int xa = 0, xb = 0;
    out [8] = '\0';

    for (int i = 0; a[i] != '\0'; i++)
        {xa = (xa << 1) | (a[i] - '0') ; }
    for (int i = 0; b[i] != '\0' ; i++)
        {xb = (xb << 1) | (b[i] - '0') ; }

    int Ea = (xa >> 3) & 0xF; int Ma = xa & 0x7;
    int Eb = (xb >> 3) & 0xF; int Mb = xb & 0x7;

    int siga = 8 | Ma; int sigb = 8 | Mb;

    int E;
    if (Ea >= Eb){
        sigb = sigb >> (Ea - Eb);
        E = Ea;
    }
    else {
        siga = siga >> (Eb - Ea);
        E = Eb;
    }
    
    int sig = siga + sigb;
    while (sig >= 16){
        sig >>= 1;
        E++;
    }

    int result = (E << 3) | (sig & 0x7);

    for (int i = 7 ; i>= 0 ; i--){
        out[i] = '0' + ((result >> (7 - i)) & 1); 
    }
}


int main(void){
    char a[16],b[16],out[9];
    
    while ((scanf("%15s %15s", a, b)) == 2){
        sum(a, b, out);
        printf("%s + %s = %s\n", a, b, out);
    }
    return 0;
}
```
