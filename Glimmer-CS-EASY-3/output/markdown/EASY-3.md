# EASY-3:二叉树与递归

## step1.什么是树

(1) ***二叉树***

- **树的定义:** 由节点和边组成的一种非线性数据结构,有唯一的根节点,呈一对多的层级关系

- **二叉树:** 可能是0个节点的空树,而对于非空树是二叉树,需满足:
  - 1.有且仅有一个根节点;
  - 2.除根结点以外的其余节点分为互不相交的两个子集,称为左子树和右子树,而左右子树本身也是二叉树;
  - 3.二叉树每个节点至多有两个子树;

- 定义二叉树以及下面的二叉树操作都在代码文件中.

- **二叉树的存储:**
  - 1.顺序存储:使用数组存放,通过下标关系定位节点.
  - 2.链式存储:使用结构体,包含数据域和左右指针.

- ***二叉树的特点:***
  - 1.每个节点最多有两个子节点;
  - 2.左右子树不能颠倒;
  - 3.即使只有一个子节点,也必须区分孩子的左右.

(2) ***思考过程***

- 用顺序表实现二叉树,精髓是下标的计算,我认为编码的同时画图可以节省思考量.按照层序遍历将节点从上到下,从左到右依次放进数组.假设根节点下标为1.对于下表为i的节点,左孩子为2i,右孩子为2i+1.
- 要初始化一个二叉树,需要保证每个数组的used值都被标记为空,此时可以执行一次循环.并且将上面定义的二叉树的节点数量设置为0.
- 创建一个根节点,需要填入数据并标记为已使用,之后将size值+1.在此之前需要检查根节点是否被占用,不被占用才能继续上述过程.
- 创建左右孩子,需要先验证是否出现下标越界或位置被占用或父节点不存在,如果通过则填入数据并标记.
- 层序遍历先验证树是否存在节点,如果存在才能遍历.从第一层的下标开始打印,有节点打印数据,反之打印-1.但是二叉树有分层的特点,所以当打印到当前层的最后一个下标时,计算下一层的最后一个下标并换行.
